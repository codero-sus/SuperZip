# G0D SZIP — Benchmarks (speed & size)

Engine **v8.1 / SZLZRC v7 format** (hyper tier — default; `--max` for the
smallest). 20 deterministic benchmark corpora (`tests/mkcorpus.sh` +
`tests/corpus20.py` regenerate them). Every roundtrip is byte-exact (`cmp`).
G0D best / G0D fast columns are freshly measured (v8.1: all-5 BWT delta
family + RLE-MTF coder 4). snappy / lz4hc / bzip2 / gzip / zstd-22 / brotli /
xz columns are frozen reference numbers from the same deterministic corpora
(sizes of fixed input do not change across runs).
